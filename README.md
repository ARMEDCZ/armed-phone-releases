# ARMED Phone – instalátor

Windows softphone pro frontu hovorů ARMED v Odoo (náhrada MicroSIP).

**Stáhnout nejnovější verzi:**
https://github.com/ARMEDCZ/armed-phone-releases/releases/latest/download/ARMED-Phone-Setup.exe

Po instalaci zadejte adresu Odoo a zvolte „Přihlásit přes prohlížeč“.
Přihlášení potvrzujte jen tehdy, když jste ho sami spustili ve své aplikaci
a kód v prohlížeči souhlasí s kódem v aplikaci.

Instalátor zatím není digitálně podepsaný; Windows SmartScreen se při první
instalaci zeptá („Další informace“ → „Přesto spustit“).

Tento repozitář obsahuje jen sestavené instalátory. Zdrojový kód je interní.
